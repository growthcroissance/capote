Code auditable

Le code correspondant à chaque version est conservé sous un tag Git. Sa consultation et sa compilation locale à des fins d’audit sont autorisées par la licence propriétaire.

Archive vérifiable

Chaque release contient l’application universelle et sa somme SHA-256. La provenance GitHub peut être vérifiée avec gh attestation verify.

Statut Apple transparent

La version actuelle est signée localement, mais pas encore notariée par Apple. macOS demandera donc une confirmation au premier lancement.
