# Prompts des concepts d’icône Capote

Les trois concepts ont été générés avec l’outil intégré Imagegen, puis chacun a
reçu une passe de simplification ciblée. Les références existantes ont servi à
identifier la palette et le contexte de marque ; elles n’ont pas été utilisées
comme cibles d’édition.

## A — Sentinelle

### Génération initiale

```text
Use case: logo-brand
Asset type: square high-definition concept for a macOS app icon and tiny menu-bar mark
Primary request: create an original symbol for Capote, a French macOS utility that temporarily keeps a MacBook awake while its lid is closed. Direction A — "Sentinelle": a minimal closed-laptop side profile whose narrow opening becomes one alert eye, enclosed by a compact protective shield silhouette.
Style/medium: vector-friendly flat logo mark, geometric, bold, minimal, professional Apple-platform utility aesthetic
Composition/framing: one centered mark inside a softly rounded macOS-style squircle, generous safe margin, extremely clear silhouette, readable at 16 px
Color palette: coral red #F54D38, near-black #171717, warm off-white #FFFAF7; also structurally viable as one-color monochrome
Materials/textures: none, pure flat shapes
Constraints: no text, no letters, no Apple logo, no light bulb, no gradients, no mockup, no 3D, no shadows, no tiny detail, no watermark, no extra symbols; convey closed lid, wakefulness, and protection in one compact mark; square 1:1 composition
```

### Passe de simplification finale

```text
Use case: precise-object-edit
Asset type: final square high-definition logo concept for a macOS app icon and tiny menu-bar mark
Input images: Image 1: edit target, Capote Direction A "Sentinelle"
Primary request: refine only the existing symbol into truly flat vector-like artwork. Make the laptop lid almost fully closed and horizontal, leaving only a narrow slit; simplify the eye inside that slit to one bold coral almond with one near-black pupil, with no white highlight and no extra eye detail. Keep the large protective shield and rounded-square app-icon composition.
Style/medium: strict flat vector logo, solid geometric fills, crisp uniform edges
Color palette: exactly coral red #F54D38, near-black #171717, warm off-white #FFFAF7
Composition/framing: centered, generous safe margin, strong silhouette readable at 16 px
Constraints: change only the simplification described; absolutely no gradients, shading, texture, glow, shadows, transparency artifacts, text, letters, Apple logo, light bulb, mockup, 3D, watermark, or extra symbols; preserve square 1:1
```

La première sortie B3 rendait le portable trop haut et donc visuellement ouvert.
La version conservée a reçu cette correction ciblée :

```text
Use case: precise-object-edit
Asset type: corrected square high-definition logo concept for a macOS app icon and tiny menu-bar mark
Input images: Image 1: edit target, Capote refinement B3 "Monolithe"
Primary request: change only the black laptop silhouette. It currently looks open and too tall. Replace it with an unmistakably fully closed laptop seen exactly from the side: a very low, wide monolithic near-black horizontal capsule, total height no more than one eighth of the icon canvas, with one razor-thin coral horizontal cut line through it. Keep the open warm-off-white circular halo, coral squircle, spacing, and all other geometry unchanged.
Style/medium: strict flat vector-like logo, solid fills, crisp edges
Constraints: the laptop must be fully closed, horizontal, low and wide; no screen angle, no trapezoid, no perspective, no power-button stem, no status dot, no text, no letters, no Apple logo, no eye, no shield, no light bulb, no extra symbol, no gradient, no shading, no glow, no shadow, no texture, no mockup, no 3D, no watermark; preserve square 1:1
```
